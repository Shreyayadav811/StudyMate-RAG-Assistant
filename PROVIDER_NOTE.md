# LLM provider note

This version uses Google Gemini API instead of Groq. Selected Gemini models currently have a free tier, but quotas, model access, and regional availability can change. Review https://ai.google.dev/gemini-api/docs/pricing before use. For a strict zero-cost setup, do not link a billing account or select a paid tier. The API free tier may be rate-limited and Google may process API prompts under the free-tier data-use terms.
